Sound effects
=============

Every .ogg file in this folder was made by Kenney (https://kenney.nl) and is
released under Creative Commons Zero (CC0 1.0 Universal):

    https://creativecommons.org/publicdomain/zero/1.0/

CC0 is a dedication to the public domain: free to use in personal, educational
and commercial work, and crediting is not required. This file exists anyway,
because "where did these come from" is a question worth being able to answer
without going through the git history.

Which file came from where, and what it was called there:

  deal.ogg    Casino Audio        Audio/card-shuffle.ogg
  deny.ogg    Interface Sounds    Audio/error_004.ogg
  drop.ogg    Interface Sounds    Audio/drop_002.ogg
  hit.ogg     Impact Sounds       Audio/impactMetal_heavy_001.ogg
  join.ogg    Interface Sounds    Audio/switch_002.ogg
  miss.ogg    Impact Sounds       Audio/impactSoft_medium_000.ogg
  over.ogg    Interface Sounds    Audio/confirmation_002.ogg
  place.ogg   Impact Sounds       Audio/impactWood_medium_000.ogg
  tap.ogg     Interface Sounds    Audio/click_002.ogg
  turn.ogg    Interface Sounds    Audio/pluck_001.ogg

Packs:

  https://kenney.nl/assets/interface-sounds
  https://kenney.nl/assets/impact-sounds
  https://kenney.nl/assets/casino-audio

The files are unedited. Levels are set at playback time in src/client/sfx.ts,
so re-cutting one of these is a matter of dropping in a replacement under the
same name.
